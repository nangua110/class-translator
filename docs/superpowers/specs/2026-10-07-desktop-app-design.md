# 课堂同传桌面版 设计文档

日期：2026-10-07　状态：待南瓜确认

## 1. 背景与目标

现在的「课堂同传」是一个本地网页工具（`~/class-translator`：Python FastAPI 后台 + 浏览器页面），南瓜自己上课用。很多中国同学也听不懂英文授课，所以要把它做成**简单安装、可公开发布**的桌面软件。

**目标用户**：在海外上课、英语听力吃力的中国学生，大多不懂编程。

**成功标准**：同学下载安装包 → 双击安装 → 跟着引导走两三步 → 开始看到中英字幕。全程不碰终端、不装 Python。

### 1.1 南瓜提出的要求
- 桌面 App + 浮动字幕小窗（看视频、网课时字幕浮在上层）
- 支持新 Mac、旧 Mac、Windows
- 公开发布
- 窗口最底下写「Powered by 南瓜」
- 旧 Mac / Windows 的语音识别用云端 Gemini
- 技术路线：Electron

### 1.2 设计中的假设（已和南瓜确认）
- 安装包里不带南瓜的 API key、课堂记录或任何个人信息；每个同学用自己的 key，不填 key 也能用免费功能（仅新 Mac）
- 功能与现网页版一致：实时字幕和翻译、课堂笔记、课后精讲（含历史记录）、电脑内部声音、导出 Markdown / PDF
- 界面全部简体中文
- App 名暂定「课堂同传」，可改；不得使用其他已有产品的名字和图标

### 1.3 必须保留的现有约定
- **翻译要结合上文、纠正识别错字**：Gemini / Claude 翻译时带前 3 句上文，并提示「语音识别可能有错字，请按语境理解」（`llm.py` 的 `TRANSLATE_SYSTEM`）。南瓜明确要求不能丢。苹果翻译只做备用。
- **只识别所选语言**：说话人语言选什么就只保留那种语言，其他语言一律忽略；「自动」才中英都要。
- **中文一律简体**：所有中文输出（字幕、翻译、笔记、精讲）都经过繁转简。

## 2. 分期

| 期 | 交付 |
|---|---|
| 1 | 新 Mac 上可用的 App：现网页版全部功能 + 苹果识别 / 苹果翻译 + key 加密保存 + 「Powered by 南瓜」 |
| 2 | 云端 Gemini 识别（旧 Mac、Windows 用）+ Windows 系统声音 + Windows 安装包（需南瓜找 Windows 电脑测试） |
| 3 | 浮动字幕窗 |
| 4 | 首次使用引导、隐私说明、Mac / Windows 正式安装包、下载页说明文字、上架 Microsoft Store |

每期单独写开发计划、单独交付。现网页版保留，App 稳定前南瓜继续用网页版上课。

## 3. 整体结构

```
Electron App
├─ 主进程（Node，后台）
│   ├─ session      一节课的流水线：音频 → 识别 → 字幕 → 翻译 → 笔记 → 存盘
│   ├─ audio        音源：麦克风（来自窗口）/ 电脑内部声音（Mac: syscap；Windows: 系统回环）
│   ├─ asr          识别引擎：apple（Swift 子程序）/ cloud（人声检测 + Gemini 音频）
│   ├─ translate    llm（Gemini / Claude）、apple（Swift 子程序）、繁转简
│   ├─ notes        课堂笔记（滚动更新）、课后精讲（两步生成）
│   └─ store        课堂记录文件、设置、加密保存的 key
├─ 预加载桥（preload）  只暴露白名单接口给窗口
└─ 窗口
    ├─ 主窗口        沿用现网页界面
    └─ 浮动字幕窗    第 3 期
```

### 3.1 和现网页版的主要区别
1. **不开本地网络端口**。现网页版靠 `localhost:8765` 的 HTTP / WebSocket 通信；App 改用 Electron 的进程间通信（IPC），窗口通过预加载桥调用后台，别的程序和网站碰不到。
2. **key 不再明文存在 `.env`**。改用 Electron `safeStorage`（Mac 存钥匙串，Windows 用 DPAPI），非机密设置存普通 JSON。
3. **后台从 Python 改写成 JavaScript**。提示词、断句参数、过滤规则、两步精讲逻辑原样移植。

### 3.2 组件说明

| 组件 | 做什么 | 依赖 |
|---|---|---|
| `session` | 管一节课：收音频、调度识别、去重、只留所选语言、推字幕到窗口、后台翻译、定时更新笔记、每句存盘 | asr、translate、notes、store |
| `audio/mic` | 窗口里用 AudioWorklet 采 16kHz 单声道 PCM，经 IPC 送到后台 | 无 |
| `audio/system-mac` | 启动 `syscap`（Core Audio Tap），读它输出的 PCM | macOS 14.2+ |
| `audio/system-win` | 窗口里用 `getDisplayMedia` + Electron 的系统回环音频，转 PCM 送后台 | Windows 10+ |
| `asr/apple` | 启动 `apple_asr`（SpeechAnalyzer），收草稿 / 确定句，按把握值和文字特征过滤其他语言 | macOS 26+ |
| `asr/cloud` | Silero 人声检测（onnxruntime）判断有人说话才切段，发给 Gemini，同时拿回转写和译文 | Gemini key |
| `translate/llm` | Gemini / Claude 翻译、笔记、精讲；Gemini 多模型轮换和冷却；Claude 可选模型 | 官方 SDK |
| `translate/apple` | 常驻 `apple_translate` 子程序；未下载语言时提示并改用 AI 翻译 | macOS 26+ |
| `notes` | 课堂笔记（每 3 分钟合并新内容）、课后精讲（先切带时间章节，再写精讲 / 术语表 / 思考题 / 核心要点） | translate/llm |
| `store` | 记录存「文稿/课堂同传」；设置 JSON；key 用 safeStorage | Electron |

三个 Swift 子程序（`apple_asr`、`syscap`、`apple_translate`）沿用现有代码，编译成同时支持苹果芯片和 Intel 的版本，随 Mac 版打包。它们由 App 启动，麦克风、系统录音权限会显示成「课堂同传」而不是「终端」。

## 5. 用户体验

### 5.1 首次打开（第 4 期做完整版，第 1 期先有简单版）
1. **检测电脑**：告诉同学这台电脑能用哪些功能。
2. **授权麦克风**：先说明用途，再弹系统授权。系统录音权限等第一次选「电脑内部声音」时再申请。
3. **填 Gemini key**：新 Mac 可以跳过；旧 Mac 和 Windows 必填，因为识别要用。附图文步骤教怎么免费申请；粘贴后立即测试，告诉同学能不能用。
4. **隐私说明**：一页简表（见第 6 节），附「录课前请确认学校和老师的规定」。

### 5.2 默认设置
- 说话人语言：英语；翻译成：简体中文
- 识别：新 Mac 用苹果，其他用云端
- 翻译：有 Gemini key 用 Gemini，否则用苹果翻译（仅新 Mac）

### 5.3 主窗口
沿用现网页界面：转写区（实时草稿 + 中英对照）、课堂笔记 / 课后精讲两个标签（含历史记录选择框）、「AI 模型与 API」设置弹窗（key 可修改 / 删除、Gemini 和 Claude 模型可选、苹果翻译状态）、导出 Markdown / PDF。底部固定一行小字：**Powered by 南瓜**。设置里增加「打开记录文件夹」。

### 5.4 浮动字幕窗（第 3 期）
- 主窗口「浮动字幕」按钮打开；半透明、始终置顶，不出现在任务栏 / 程序坞
- 显示最近 1–2 句原话 + 译文，最下一行是灰色实时草稿
- 可拖动、可拉伸；字号大 / 中 / 小三档；「只显示中文」开关
- 关掉小窗不影响主窗口继续录制；不放署名，免得挡字幕

### 5.5 关于窗口
App 名、版本号、Powered by 南瓜、「检查新版本」链接（打开发布页）。

## 6. 隐私与数据

| 功能 | 数据去向 |
|---|---|
| 苹果识别、苹果翻译 | 只在本机处理，不上传 |
| 云端 Gemini 识别 | 有人说话的音频片段发给 Google |
| Gemini / Claude 翻译、笔记、精讲 | 转写文字发给 Google / Anthropic |
| 南瓜 | 收不到任何数据：App 内没有统计、没有上传、没有南瓜的服务器 |

- 设置里每个云端选项旁写明「会发送到 Google」或「会发送到 Anthropic」。
- 本地只存：课堂记录和课后精讲（「文稿/课堂同传」，用户可自行删除）、设置、加密的 key。
- key 在界面上只显示末 4 位，不写进任何文件或日志。
- **打包检查**：安装包里不得包含 `.env`、`records/`、`.venv/`、任何 key。打包脚本里加自动检查，命中即失败。
- 是否允许课堂录音由学校和老师决定，App 只做提醒，不下结论。

## 7. 出错处理

| 情况 | 处理 |
|---|---|
| Gemini 额度用完 / 繁忙 | 自动换其他 Gemini 模型；新 Mac 上翻译改用苹果翻译顶上并提示一次；都不行时在字幕区写明原因和大约恢复时间 |
| 没网 | 新 Mac 继续用苹果识别和翻译；其他电脑提示「需要联网才能识别」 |
| key 无效 | 保存时测试，马上提示 |
| 没给麦克风 / 系统录音权限 | 弹出说明 + 按钮直接打开系统设置对应页面 |
| 苹果翻译语言未下载 | 提示并给出打开设置页的按钮；下载前先用 AI 翻译 |
| 子程序退出（苹果识别等） | 自动重启一次；再失败就改用其他识别方式并提示 |
| App 崩溃 | 每句字幕识别出来就立即存盘；重开后能在历史记录里找到这节课并生成课后精讲 |

## 8. 测试

- **自动测试**（Node 自带测试框架）：断句、只留所选语言、苹果识别结果过滤、繁转简、去重、课后精讲格式、key 不进日志 / 文件。每期都跑。
- **真实测试**（在南瓜的 Mac 上）：用合成讲课录音按实时速度测试麦克风、电脑内部声音、苹果 / 云端识别、三种翻译方式、课后精讲生成和 PDF 导出。
- **需要南瓜帮忙**：Windows 电脑按清单试一遍（约 10 分钟）；如有低于 macOS 26 的 Mac 也试一遍；用一两节真实课堂试用。

## 9. 打包与发布

### 9.1 安装包
- Mac：`.dmg`，拖进「应用程序」即可；同一个包新旧 Mac 通用，启动时判断能力。
- Windows：`.exe` 安装程序（NSIS）；另出 Microsoft Store 用的 MSIX 包。
- 用 electron-builder 在这台 Mac 上打出两个平台的包。

### 9.2 系统安全提示（不使用任何绕过手段）
- **Windows（推荐上架 Microsoft Store）**：个人开发者免费注册，商店应用由微软签名，安装无警告、可自动更新；首次上架需审核。备选：开源后申请免费代码签名计划（如 SignPath Foundation）；或直接发 `.exe`，靠下载量逐步积累信誉，初期会有「Windows 已保护你的电脑」提示。
- **Mac**：先问学校是否参加苹果教育开发者计划，有账号就做公证，打开无警告；没有就先不签名发布，下载页附图文步骤（系统设置 → 隐私与安全性 → 仍要打开），用户多了再买开发者账号（每年 99 美元），可考虑放捐赠链接分摊。
- 不做：偷偷关闭系统检查、冒用他人证书、伪装文件等任何规避手段。

### 9.3 下载与更新
- 发布在 GitHub Releases（用南瓜自己的账号；上传、公开前都先征得南瓜确认）。
- 第一版不做自动更新，「关于」里放检查新版本链接。

## 10. 不做的事（第一版）
- 本地 Whisper（旧 Mac / Windows 只用云端）
- 自动更新
- 账号系统、云同步、任何服务器
- Linux 版
- 手机版

## 11. 风险
- **Windows 无法在这台 Mac 上实测**：系统回环录音、麦克风权限、安装流程都要靠南瓜找电脑测试。
- **Gemini 免费额度**：一天多节课可能用完；界面要把原因和恢复时间说清楚，并引导同学自行决定是否付费。
- **苹果 SpeechAnalyzer / Translation 是新接口**：系统更新可能改变行为，需要在每次大版本系统更新后回归测试。
- **未签名发布的门槛**：部分同学可能被安全提示劝退；下载页说明要足够清楚。
